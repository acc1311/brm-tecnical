Comenzi primite

Cum conectezi Google Sheets pentru comenzi (o singură dată)
  1. Deschide sheets.new → foaie nouă („Comenzi BRM”).
  2. Extensions → Apps Script → șterge tot → lipește codul din gs/comenzi.gs → Save.
  3. Deploy → New deployment → Web app: Execute as = Me, Who has access = Anyone → Deploy → copiază URL-ul.
  4. Lipește URL-ul în Setări → „URL Comenzi” → Salvează setările → Publică online.

Comenzile din coș se scriu automat în foaia „Comenzi” și apar aici. Comenzile trimise pe email funcționează oricum.
